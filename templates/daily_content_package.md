## 14. 事实、隐私、版权和夸张表达检查

- [ ] 所有进展、成果、错误和数据均有真实记录
- [ ] 没有把计划或AI建议写成已完成结果
- [ ] 没有虚构粉丝评论或问题

- [ ] 开头0—8秒先展示最终效果、前后对比或真实结果证据
- [ ] 正文讲观众怎样使用AI，而不是文件名、Git、接口和代码实现
- [ ] 每个关键方法都有真实界面、第一版、返修或前后对比画面

- [ ] 正文至少三次把个人经历翻译成观众可用的判断或动作
- [ ] 已选择最适合证据的主结构，没有把短题材强行拉成长稿
- [ ] 框架每项都有具体动作和做完后的可观察信号，不是口号
- [ ] 已说明个人证据作用、个人变化和适用边界
- [ ] 评论问题、观众任务和下一集理由均已策划，但口播结尾只保留一个自然主收束
- [ ] 语气轻松自然，至少有一个不影响事实的自嘲或反差点
- [ ] 使用热梗时已记录来源、核验日期和适用语境；没有合适热梗时没有强行插入
- [ ] 没有使用“你怎么看”“欢迎留言”“记得点赞关注”等空泛互动口号
- [ ] 截图和文件已移除密钥、令牌、Cookie、密码和私人信息
- [ ] 第三方素材拥有权限或已用自制画面替代
- [ ] 标题和封面没有夸大成果、耗时、收入或效果
- [ ] 热点观点没有被写成事实
- [ ] 医疗、金融、法律等高风险信息已人工审核或删除
