## 两条高播放视频的包装基线

- [ ] 正文 authored start 约为 0.01 秒，实际可听人声不晚于 0.03 秒
- [ ] 0—5.5 秒完成强观点、冲突、损失或真实结果
- [ ] 品牌片只在第一个完整语义段结束后出现，时长约 3 秒
- [ ] 品牌片期间没有正文人声、上一段残留字幕或下一段提前字幕
- [ ] 每 2—4 秒有一个解释当前语义的视觉变化
- [ ] 6—8 秒长句至少拆成两个独立视觉节拍，没有借用下一句话的总结动效
- [ ] 字幕使用完整语义句或自然分句，每屏最多一行
- [ ] 真实页面、终端、笔记、原视频名称和测试数字优先于自绘替代
- [ ] 封面采用真人背景和两行超大冲突/后果文案，并分别生成四画幅
- [ ] 最终响度约 -16 LUFS，真峰值不高于 -1.5 dBTP
- [ ] 发布包与最终母版 SHA-256 绑定，且 `autoPublish=false`
