## 基线明确优势

1. 结果先行，而不是先讲开发过程。
2. 真实旧视频、真实工作台截图和人物画中画构成证据链。
3. 六个语义段使用不同视觉结构，不是重复横幅。
4. 字幕、信息卡和证据各自承担不同任务。
5. 剪辑点与音频使用同一时间边界，口型同步稳定。
6. 声音只在少数语义转折使用，未覆盖人声。

## 基线可改进点

1. 科技深色 UI 仍带有较强“内部工具演示”气质，普通用户的通用感不足。
2. 部分段落同时出现标题、摘要、事实卡和证据，信息密度偏高。
3. 三条旧视频虽形成版本墙，但单条差异的识别时间较短。
4. 结尾总结与 CTA 连续出现，节奏停顿还可更明确。

## 挑战版平台级改动

本次不为 `new.mp4` 写死时间线，而是新增通用机器合同：

- `sceneRole`：`hook`、`proof-montage`、`thesis-takeover`、`ui-demo`、`revision-flow`、`learning-summary`、`cta`、`explanation`；
- 语义角色决定安全默认布局，模型失败时也不会全部退化为左右卡片；
- 真实证据支持 `montage-left`、`montage-center`、`montage-right`、`ui-main`、`proof-primary`；
- 核心问题、返修流程、学习总结和 CTA 有不同的 HTML 结构与动效靶点；
- 素材仍需本地入库、逐项审核、冻结文件哈希和绑定成片时间段。

## 主观验收

挑战版必须在下列六项中至少四项胜出，且其余项无明显退步：

1. 开场钩子
2. 理解成本
3. 视觉层级
4. 节奏
5. 字幕
6. 音画同步

最终结论只由隐藏标签 A/B 的用户偏好决定。技术测试、Agent 自评或“链路跑通”都不能替代主观胜出。
