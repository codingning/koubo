# Creator Vault 私有任务知识 Trial v3 验收

日期：2026-07-31

## 最终结论

第三阶段完成了真正的 Agent 私有知识闭环，但三张任务卡没有证明能够稳定提高 Content Strategist 的分析质量。

原五题和五个未参与卡片设计的新场景均未通过固定门槛，因此三张卡已经从 `content.private/trial` 转为 `rejected`：

- 不再参与默认或显式 trial 检索；
- 不进入真实稿件或 Script Agent；
- 不进入 `approved` 或 `promoted`；
- 不改变生产默认、发布或批准权限；
- 保留来源、评测、状态转换和显式回滚记录。

这不是系统失败。系统正确完成了“提出候选 → 隔离试用 → 原题回归 → 未见题泛化 → 失败淘汰”的训练治理闭环。

## 实现内容

### Creator Vault

- 新增 `content.private` 私有任务卡导入；
- 只有 `content-strategist` 的命名空间允许读取；
- 卡片必须绑定评测 artifact、仓库提交和 SHA-256；
- 只能通过技术准入进入 `trial`；
- `rejected` 卡重新导入时保持终态，不会被自动恢复为 trial；
- 导入前完整快照：`G:\CreatorVault-Backups\vault-snapshots\20260731-165450-before-private-task-import`。

### Koubo

- Content Strategist 支持两种知识来源：公开视频时间码原则和内部评测 artifact 任务卡；
- 私有卡必须包含所需证据、决策步骤、失败信号、适用条件和反例；
- 通过相对相关性门槛，任何方向最多读取真正匹配的私有卡；
- 知识桥等不相关方向不会读取私有任务卡；
- 新增五个未见场景，避免只针对原五题优化。

## 为什么仍然没有变聪明

基础模型已经能够从完整的用户事实、证据和约束中推导出多数正确步骤。任务卡主要带来：

- 更详细的字段和检查项；
- 更完整的治理边界；
- 更明确的失败分类；
- 更严格的对照要求。

但盲评更关心这些新增内容是否改变了核心判断并改善下一步决策。多数情况下，Control 已经能给出同等级判断；Trial 只是换一种方式展开，因此形成 Tie。

这说明仅把“观点、规则和框架”写进知识库，通常只能让回答更有结构，不能自动让 Agent 在具体任务上更有能力。

## 对 Agent 训练路线的修正

下一阶段不应继续给 Content Strategist 增加建议型知识卡，而应转向 Agent 原生任务数据：

1. **Sound Agent**：输入真实时间线、语义触发点和候选音效，输出候选排序与精确放置时间；用用户接受、拒绝或整组不合格作为标签。
2. **Caption Agent**：输入真实转录、语速和画面空间，输出强调词及动效密度；用真实样片审核作为标签。
3. **Content Strategist**：保存用户最终采用、否决或修改的方向分析，而不是只保存外部博主观点。
4. **经验复用**：同一规则必须在后续任务中留下“调用记录 → 真实输出 → 人工结果”，才能重新进入 trial。
5. **模型微调**：只有积累足够的正负决策样本后再评估；当前仍不具备微调数据门槛。

知识库仍然有价值，但应主要承担证据、样本、状态和检索；真正的能力提升要来自任务级输入输出和结果反馈。
