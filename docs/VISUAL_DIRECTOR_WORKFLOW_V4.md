# Visual Director Workflow v4

状态：Ready；来源：用户于 2026-07-22 确认 `1A 2A 3A`。

## 目标

把已经验证的“参考视频风格分析 → 口播内容拆解 → 关键帧 → 动态样片 → 完整成片”流程设为新任务默认路径，同时保留旧 FFmpeg v3 路径作为历史任务兼容与渲染降级方案。

## 六个网页阶段

1. **同题视频搜索与风格分析**：自动搜索抖音同题视频，也接受手动链接；保存来源、证据等级、风格报告和复用边界。
2. **ASR、语义剪辑与内容拆解**：本地转录与保守删减；每段产出大意、标题、重点句、摘要、实际需要的0—3张事实卡、右侧视觉和参考包装方式，不为凑数量补占位卡。
3. **3—5张关键帧**：1920×1080，使用真人关键画面验证构图、层级、颜色和人物安全区。
4. **关键帧审核门**：必须整组批准；返修会使后续样片和完整成片失效，但保留历史版本。
5. **15—25秒动态样片**：1920×1080；标题 → 摘要 → 事实卡 → 二维动效按顺序推进。必须批准后才能进入完整渲染。
6. **完整视频与QA**：HyperFrames 生成 2560×1440、30fps 的2K母版，另生成1080p审核版、上下文小样、素材manifest和QA。

## 配置模型

- 默认值和默认提示词位于 `config/video_workflow_v4.json`。
- 网页同时提供结构化字段与可展开的高级提示词。
- 用户不修改时直接使用默认值；修改只作用于当前任务，并写入任务目录。
- 每次运行生成新版本，不覆盖原始视频、旧提示词、旧模型输出、旧关键帧或旧成片。
- 关键帧、样片和最终成片是三道人工审核门；不会自动发布。

## 兼容策略

- 新建任务默认 `pipeline=visual-director-v4`。
- 没有 `workflow` 字段的旧任务继续使用现有素材审核、FFmpeg渲染和最终审核界面。
- HyperFrames 不可用时只允许明确记录后降级到 FFmpeg v3；不得把降级产物伪装为 HyperFrames 成片。

## 完成标准

- 六个阶段都可在网页查看配置、编辑高级提示词、保存并重跑。
- 风格报告和内容拆解保存为结构化 JSON。
- 关键帧实际生成3—5张图片并可逐张查看。
- 未批准关键帧不能生成样片；未批准样片不能生成完整成片。
- 最终母版为2560×1440，审核预览为1920×1080。
- 旧任务仍可打开和返修；所有新旧版本均可追溯。

## 2026-07-25 动态编排执行合同

- `motion_sample` 的 `choreography.at` 统一表示相对 `sampleStart` 的样片内时间；非人物元素绑定 `segmentId`，目标只允许标题、重点句、摘要、实际存在的事实卡、主视觉和人物。
