# 两条高播放视频的复用基线

日期：2026-07-31

状态：`preferred-experimental-baseline`

## 结论先行

用户明确反馈，下面两条已经发布的视频播放量相对较高，因此其中重复出现的内容结构、品牌位置、字幕、声音、封面和发布方式应被保留为下一阶段的优先实验基线：

1. 抖音收藏转 Obsidian：`douyin-obsidian-old-favorite-proof-v1`
2. 蒸馏抖音博主 Skill：`douyin-creator-distill-jiang-v1`

这是两个真实发布样本和用户确认的结果信号，但目前没有保存具体播放量、3 秒留存、5 秒留存、完播、主页点击、收藏、评论关键词或资源领取数字。本文可以指导下一条视频优先复用什么，不能证明其中某一个剪辑手法单独造成了播放增长。

## 共同有效的内容结构

### 1. 前 3–5 秒先抛观点和矛盾

- 收藏视频用“收藏不等于学会”建立认知冲突。
- 博主蒸馏视频用“蒸馏强者，让他给你打工”建立利益和争议。
- 开头不是介绍项目、功能列表或个人背景，而是直接说观众正在经历的损失、矛盾或可得到的结果。
- 强观点后必须立刻补真实边界。比如“让他给你打工”后马上说明不是抄原句、模仿人设或复制口吻。

### 2. 抽象能力必须跟真实证据

- 不只说“能整理收藏”，要展示真实抖音收藏页、真实旧收藏、真实笔记和完成数字。
- 不只说“能蒸馏博主”，要说明实际采集数量、逐视频笔记数量、跨视频综合和可追溯来源。
- 数字、页面、原视频名称、终端输出和测试结果承担证明任务；装饰卡片不能替代证据。

### 3. 只讲一个明确闭环

两条视频都没有扩展成完整产品介绍，而是围绕一个闭环推进：

`观众痛点或强观点 → Skill 做什么 → 真实运行 → 结果证据 → 使用边界 → 单一关键词 CTA`

## 品牌片位置与规则

品牌片不固定卡在绝对第 3 秒，而是固定放在“第一个完整语义段结束之后”。本次两个有效位置分别为 5.5 秒和 6.47 秒。

必须同时满足：

1. 开头观点已经完整说完，不能为了品牌片截断上一句话。
2. 品牌片长度约 3 秒；当前验证值为 3.00 秒和 2.99 秒。
3. 品牌片期间不播放正文人声，上一句必须完全结束。
4. 品牌片前允许保留约 0.5 秒呼吸空隙，第二条实际为 0.58 秒。
5. 品牌片可以有独立 Sonic Logo，但声音不能盖住相邻正文。
6. 品牌结束前可预滚下一段底层画面，避免切出白屏；字幕和人声仍按正式时间进入。

因此，后续默认规则是“完整钩子后 3 秒无口播品牌片”，不是“机械地在第 3 秒插品牌”。

## 字幕基线

- 使用完整语义句或自然分句，禁止逐字和两字卡拉 OK。
- 每屏最多一行；句子过长时先重新分句，再考虑缩小字号。
- 字幕只复述真实人声；信息卡负责结论、结构和证据，两者不能重复占据同一层级。
- 入场动效保持轻量，约 120–220ms 的上浮、缩放或硬切即可；重点词可改变颜色或硬阴影。
- 品牌片期间不显示上一段残留字幕，也不提前显示下一段字幕。

## 视觉与动效基线

- 每个关键语义必须拥有自己的视觉变化，不能借用下一句话的收束动效。
- 2–4 秒应出现一次有意义的状态变化：对象进入、真实页面移动、步骤推进、证据组装、关键词替换或数字落锤。
- 任何持续 6–8 秒的句子至少拆成两个视觉节拍。博主蒸馏视频 65–73 秒最终拆为“研究方向依次出现 → 点击问 AI → 观点/结构/来源分三拍返回”。
- 画面上方、人物安全区或主信息区不能长时间空置；但补充内容必须解释当前台词，不能为了填空添加无关装饰。
- 真实页面优先于自绘替代。涉及收藏页、终端、Obsidian、原视频或测试结果时，应尽量使用真实界面。
- 动效结束点必须与当前语义结束对齐；边界、总结和 CTA 动效不得提前出现。

## 声音基线

- 第一段正文从约 0.01 秒开始，实际可听人声必须在 0.03 秒以内；音频素材的前导静音要测量和裁切/预滚，不能只看 authored start。
- 使用按语义段生成和筛选的情绪配音，不再整篇一次生成。痛点、解释、证据、边界和 CTA 使用不同表演弧线。
- 异常读音、机械感、无意义插词和情绪过平都属于发布阻断项。
- 默认不使用持续 BGM；只在关键语义节点放稀疏 SFX，确保人声始终清楚。
- 最终母版目标为约 `-16 LUFS`，真峰值不高于 `-1.5 dBTP`；若渲染结果偏响，只重编码音频并验证视频码流不变。

Qwen3-TTS 本人音色的授权、完整 ICL、分段表演、双候选、自动预筛、人工试听和定点重生成规则，详见 [Qwen3-TTS 本人音色情绪配音基线](./2026-07-31-qwen3-tts-emotional-voice-cloning.md)。

## 封面基线

当前优先模板为“真人背景 + 两行超大冲突文案”：

- 真人原片铺满，不使用纯黑底、抽象科技底或强个人品牌框。
- 文案优先表达冲突、后果或强利益，不写完整功能说明。
- 两行文字允许遮挡人物，手机端可读性高于人脸完整露出。
- 重点词使用蓝、黄等高对比色，其余文字使用白色并配粗黑描边/阴影。
- 9:16、3:4、16:9、4:3 必须独立排版，不能只做机械裁切。
- 封面和发布文案必须绑定最终母版 SHA-256；覆盖旧文件时使用新版本名，避免客户端缓存让不同版本看起来相同。

本次封面语法：

- 收藏视频：`收藏≠学会 / 越存越没用`
- 博主蒸馏视频：`蒸馏强者 / 让他给你打工`

## CTA 与发布材料包

- 结尾只保留一个动作和一个关键词，不连续要求评论、关注、进群和私发。
- 收藏视频关键词为“知识库”；博主蒸馏视频关键词为“蒸馏”。
- CTA 应明确观众能得到什么具体资源，例如 Skill、配置、模板或知识库，而不是泛泛“想要的留言”。
- 用户批准最终 MP4 后，一次生成：四画幅封面、3 个标题候选、抖音/小红书/视频号文案、4–8 个话题、JSON、Markdown 和 ZIP。
- 生成发布包不等于自动发布；`autoPublish` 必须保持 `false`。

## 下一条视频的默认检查点

- [ ] 0.03 秒内可听到正文人声
- [ ] 0–5.5 秒完成强观点、冲突或真实结果
- [ ] 第一完整语义段结束后再进入约 3 秒品牌片
- [ ] 品牌片期间没有正文人声和残留字幕
- [ ] 每个 2–4 秒语义节拍有对应画面变化
- [ ] 任何 6–8 秒长句至少有两个独立视觉节拍
- [ ] 真实证据能够支持稿件中的数字和能力声明
- [ ] 字幕按完整语义句/分句出现且每屏最多一行
- [ ] Qwen3-TTS 配音已按语义段设计情绪、生成候选并经人工试听确认
- [ ] ASR 未发现奇怪插词、误读、英文机械读音或专有名词错误
- [ ] 封面使用真人背景和两行超大冲突/后果文案
- [ ] 结尾只有一个关键词 CTA
- [ ] 母版通过完整解码、响度、真峰值、首帧出声和哈希检查
- [ ] 发布包绑定最终母版且 `autoPublish=false`

## 数据回填要求

后续发布必须尽量记录：发布时间、播放量、3 秒/5 秒留存、平均播放时长、完播、主页访问、收藏、评论关键词数量和资源领取数量。只有具备这些数据，才能继续判断“强观点、品牌片、真实证据、字幕、封面或 CTA”分别对传播和转化产生了什么影响。
