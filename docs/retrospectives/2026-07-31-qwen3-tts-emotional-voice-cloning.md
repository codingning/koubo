# Qwen3-TTS 本人音色情绪配音基线

日期：2026-07-31

状态：`preferred-experimental-baseline`

## 结论先行

这次有效的经验不是“让模型听起来像本人”就结束，而是同时满足两件事：

1. 使用用户明确授权的本人原片作为音色和情绪参考，在本机完成完整 ICL 克隆。
2. 把整篇稿件拆成语义段，分别设计表演目的、生成候选、检查错读并人工试听，确保声音有观点、有情绪起伏、像真人在表达。

仅有相似音色但语气平、节奏机械、出现奇怪插词或英文误读，都属于发布阻断项。

## 已验证配置

- 模型：`Qwen3-TTS-12Hz-0.6B-Base`。
- 运行方式：Windows 本地运行，不上传参考音频、文案或生成音频。
- 克隆模式：完整 ICL，`x_vector_only_mode=false`；不能降级成只提取说话人向量后宣称“情绪克隆”。
- 参考素材：用户明确授权的本人真人原片，优先选择语速自然、情绪明显、噪声较低且包含完整长句的片段。
- 生成单位：按完整语义段生成，本次共 15 段，每段至少 2 个候选。
- 预筛：本地 faster-whisper 转录，加音高跨度、能量范围、停顿比例等指标。
- 最终决策：人工试听；自动分数只能淘汰明显错误，不能证明“像本人且有情绪”。

本次首段入选候选的观测值约为：

- `pitchSpreadSemitones=19.293`
- `energyRangeDb=13.422`
- `pauseRatio=0.301`

这些数值只作为本次候选间的比较证据，不应固化为跨文案的绝对阈值。

## 情绪表演弧线

生成前先给每个语义段标注表达任务，而不是整篇只写一个“更有情绪”：

| 语义任务 | 表演方向 | 常见错误 |
|---|---|---|
| 强观点/钩子 | 立即进入、重音明确、有确信感 | 前导静音、声音太软、像念标题 |
| 观众痛点 | 有代入感和轻微焦虑，但不卖惨 | 全程同一音高、停顿位置生硬 |
| 解决方案 | 语气转亮、速度略提、像真的找到办法 | 兴奋过度、关键词粘连 |
| 真实证据 | 稳定、清楚、数字和专有名词准确 | 数字误读、证明段仍像广告 |
| 边界说明 | 放慢一点、可信、不含糊 | 语气突然泄掉、像免责声明朗读 |
| CTA | 简短、自然、带邀请感 | 喊麦、英文词机械、尾字没收住 |

同一条视频允许不同段落有明显情绪变化，但人物音色、基础语速和空间感必须连续，不能像多个说话人拼接。

## 生成与筛选闭环

1. 从已批准稿件拆出完整语义段，避免在一句话中途切断。
2. 为每段写明表演任务和关键词重音。
3. 使用同一份授权参考音频和参考文本，以完整 ICL 模式生成至少两个候选。
4. 用本地 ASR 检查漏字、错字、无意义插词、数字和专有名词。
5. 用音高跨度、能量范围和停顿比例做候选预筛，排除明显过平或异常音频。
6. 人工逐段试听“像不像本人、有没有情绪、是否自然、是否准确”，再检查相邻段拼接连续性。
7. 只对问题段定点重生成，不因为一处误读重新生成整篇。
8. 合成时间线后再次试听完整视频，确认情绪弧线没有被剪辑、音效或品牌片破坏。

## 已出现的失败与修复

- **情绪太平**：不能只提高音量或配 BGM；重新选择更有表达力的参考片段，并按语义段重生成候选。
- **奇怪插词/误读**：ASR 发现后定点重生成，人工确认不能只依赖转录文本。
- **英文词机械**：画面可以保留 `Skill`，旁白改读“技能”；本次 CTA 因此单独重生成。
- **首段出声太晚**：第一段 WAV 测得约 0.293 秒前导静音，通过 `data-media-start="0.28"` 预裁切；authored start 约 0.01 秒，实际可听约 0.023 秒。
- **分段拼接不连续**：统一参考音频、响度、采样率和空间感，并完整试听跨段落、跨品牌片的连接。

## 母版标准

- 输出统一为 48 kHz。
- 使用 FFmpeg 两遍 `loudnorm`，目标约 `-16 LUFS`，真峰值不高于 `-1.5 dBTP`。
- 第一段 authored start 约为 0.01 秒，实际可听人声不晚于 0.03 秒。
- 品牌片期间不得存在正文人声，品牌前一句必须完整说完。
- 音频返修时优先只重编码音频，并验证已批准视频码流不变。
- `flash-attn` 或 SoX 缺失不等于流程失败；本次本地生成、ASR、裁切、WAV 输出和 loudnorm 均完成，且没有云端回退。
