# 创作者档案

## 当前账号定位

- **定位状态**：active，2026-07-29废止“30天AI成长/普通人行动实验”定位。
- **核心受众**：已经使用AI编程，希望把 Codex、Agent、Skill 和开源组件变成稳定工作流的开发者与进阶用户。
- **一句话定位**：把 Codex、Agent 和 Skill 真正跑通，交付能复用的提示词、流程图、清单和模板。
- **创作者角色**：Windows 本地实测型 AI Builder。先安装、运行、失败、修复和验证，再公开结论。
- **账号承诺**：只讲有直接证据的运行结果；明确许可证、安全、维护、兼容性和能力边界；不复述 README 冒充实测。
- **选题机制**：不设30天、Day编号、日更或每日目标。根据当前证据从开放选题池选择，不因日期凑内容。

## 观众为什么看

- 快速判断一个 Skill、Agent 工作流或开源项目是否值得使用；
- 获得可以直接复制的提示词、流程图、检查清单或模板；
- 看见真实安装、输入、输出、错误、修复和边界；
- 避免在许可证、安全、Windows兼容性和维护状态上踩坑；
- 学会把零散AI能力组合成可回滚、可验收的工作流。

## 开放选题池

不设置固定比例和发布顺序。只有存在真实证据和可交付资产时才进入候选。

| 选题池 | 必须回答 | 最低证据 | 可交付资产 |
|---|---|---|---|
| Skill真实跑通 | 解决什么问题，怎样安装、调用和验证 | 官方来源、固定版本、真实运行结果 | 安装清单、提示词、配置模板 |
| Agent工作流拆解 | 输入、角色、工具、人工门和失败恢复怎样连接 | 流程图、一次完整运行、失败或回滚记录 | 工作流图、执行提示词、验收清单 |
| 开源项目审计 | 是否值得装，适合谁，不适合谁 | 源码关系、许可证、安全、维护、Windows试用 | 审计表、安装步骤、替代方案清单 |

个人项目只作为证据库。一个大型项目应拆成多个观众可独立使用的问题，不拍完整项目进度汇报。

## 内容交付合同

每条视频必须同时满足：

1. 只服务一个明确场景和一个核心问题；
2. 0—5秒展示可运行结果、前后差异、失败画面或交付物；
3. 给出观众能复现的最小步骤和完成信号；
4. 展示真实命令、界面、文件差异或输出证据；
5. 说明适用对象、限制和未经验证部分；
6. 至少交付提示词、流程图、清单或模板中的一种。

## 资源与社群边界

- 视频内给出足以独立理解和执行的核心方法，不故意扣留关键步骤；
- 抖音群承接可下载文件、索引、更新通知和同题讨论；
- 微信群可承接深度答疑、版本迭代和成员案例，但导流方式必须先核对当前平台规则；
- 不虚构“很多人都在领”、名额、截止时间或群内反馈；
- 每个资源必须有明确名称、版本、适用范围和领取后能得到的文件清单。

## 默认表达

- 结果先行、短句、口语化，允许专业术语，但要马上说明它解决什么问题；
- 不用“今天来分享一下”“我最近做了一个项目”作为开头；
- 不把代码、命令和配置自动降级为幕后内容：当它们是受众收益时，应直接展示并解释；
- 不强制热梗、自嘲或情绪表达；内容价值和可复现性优先；
- 不使用泛成长、成功学、职业自由和连续打卡叙事；
- 结尾只保留一个自然动作，不连续念评论、关注、加群和下期预告。

## 自适应结构

| 结构 | 适用题材 | 建议时长 | 必须交付 |
|---|---|---:|---|
| `quick-proof` 快速实测 | 一个 Skill、一个提示词或一个明确结果 | 25—45秒 | 结果、最小步骤、资产、边界 |
| `evidence-story` 失败修复 | 有真实失败、修复和前后差异 | 45—90秒 | 问题、修复、验证、复用规则 |
| `saveable-map` 工作流图 | 观众需要阶段、角色或检查顺序 | 45—110秒 | 3—5步、完成信号、流程图 |
| `deep-audit` 深度审计 | 开源库、框架或复杂工作流评估 | 60—150秒 | 来源、许可、安全、安装、结论 |

时长由信息密度决定，不为满足格式拉长稿件。

## 可公开证据规则

优先展示：官方仓库和文档、固定版本、脱敏命令、真实输出、失败日志、测试结果、前后差异、流程图、许可证与维护证据。

禁止公开：密码、API Key、Token、Cookie、私钥、恢复码、私人聊天、客户数据、未授权仓库、公司内部信息和无法证明的效果。

## 尚待验证

- 三类选题中哪一类能同时提高5秒留存、收藏和资源领取；
- 最合适的单条时长与信息密度；
- 抖音群与微信群的合规承接方式和实际转化；
- 观众更需要可安装 Skill、提示词模板，还是完整 Agent 工作流。
