# 创作者档案

## 账号定位

- **定位状态**：active，2026-07-15由综合热点口播调整为AI实践成长账号。
- **一句话定位**：一个普通人从零学习AI、使用AI完成真实项目，每天公开进度、结果和踩坑。
- **账号承诺**：只讲真实做过的任务、真实产物、真实错误和真实验证；不把课程笔记伪装成成长，不把AI生成的想象当经历。
- **第一阶段**：30天AI实践成长计划。

## 默认观众

18—40岁，对AI感兴趣但不一定有技术背景，希望看到普通人如何把AI真正用到工作、创作和项目中的中文用户。

## 观众为什么看

- 看真实项目如何从0到1，而不是只听工具介绍；
- 看AI在哪些步骤有效、哪些步骤会犯错；
- 获得可以复用的工作方法、检查方法和避坑经验；
- 连续追踪一个普通人在30天内能做到什么。

## 初始内容结构

| 内容支柱 | 比例 | 核心证据 |
|---|---:|---|
| 真实AI成长日志 | 45% | 当天任务、进度差异、昨天挑战验证结果 |
| AI工具和真实项目实验 | 30% | 文件、功能、运行结果、前后对比、失败记录 |
| AI热点亲测和普通人解读 | 15% | 与当前路线直接相关的热点 + 亲手测试结果 |
| 成长反思和真实粉丝共创 | 10% | 周复盘；真实评论或问题，未收到时留空 |

## 固定栏目

- 《普通人学AI第X天》
- 《今天被AI坑了一次》
- 《我用AI做了个真东西》
- 《这个AI热点我亲手试了》
- 《AI学习周报》
- 《粉丝问题我来实测》——必须附真实问题来源，不得虚构

## 默认表达

- 自然、真诚、口语化；
- 先给结果或失败，再解释过程；
- 承认AI做不到和自己判断错的部分；
- 不使用新闻播音腔、课程总结腔和成功学口号；
- 不说“大家好”“今天来分享一下”“记得点赞关注”。

## 可公开证据规则

优先展示：

- 项目目录和文件名，但隐藏私人路径中的个人信息；
- 自己创建的文档、表格、页面、图片和代码结果；
- 终端成功输出、测试结果和非敏感错误；
- 修改前后对比；
- 脱敏后的流程图和截图。

禁止公开：

- 密码、API Key、令牌、Cookie、私钥、恢复码；
- 私人聊天、未授权文件、客户数据、精确个人身份信息；
- 其他创作者的完整视频、文案、头像和受版权保护素材；
- 无法证明的学习成果、收入、粉丝反馈和项目效果。

## 尚待用户逐步确认

- 账号名称和昵称；
- 是否真人出镜；
- 主要拍摄环境和设备；
- 本人自然语速、常用词和禁用口头表达；
- 是否公开具体代码、仓库名和电脑路径；
- 30天后长期主攻的AI项目方向。
