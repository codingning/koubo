## 2. D1：先锁定素材和内容，再投入精包装

### 可迁移判断

1. **剪辑前先做素材预检。**
   - 时间码：`01:00–01:28`。
   - 作者先识别不同机位色温不一致、构图越界、人物姿态和画面瑕疵，再决定裁切、调色或使用替代画面。
   - Director 含义：输入存在结构性缺陷时，不能直接进入动效设计；先记录可修复项、不可修复项和补救方式。

2. **粗剪的目标是确定内容和结构，不是提前完成包装。**
   - 时间码：`04:01–05:55`。
   - 作者把口误、重复、口水词、过长停顿、机位选择和瑕疵补救放在同一粗剪阶段。
   - Director 含义：先形成语义连续、镜头可用的基础轨，再让 Caption、Motion 和 Sound 开始工作。

3. **昂贵包装前设置内容确认门。**
   - 时间码：`05:53–06:39`。
   - 作者明确建议先让委托方确认粗剪内容，否则完成文字和画面包装后再改会造成大量返工。
   - Koubo 迁移：用户方向确认和稿件确认之后，还应在真实素材粗剪完成时冻结一次内容时间线；未经确认不得扩大为全片包装。

4. **片头和章节文字应概括内容。**
   - 时间码：`06:42–07:10`、`26:59–27:24`。
   - 作者用高光或总结作为片头，并让进度条章节文字概括每段核心。
   - Director 含义：片头、章节条和信息卡必须承担导航或总结作用，不能只是装饰。

5. **文字包装只突出真正的语义重点。**
   - 时间码：`08:03–08:21`。
   - 作者明确把关键词突出解释为帮助观众直接理解当前表达。
   - Director 含义：同一句话不应同时被字幕、标题、花字和信息卡完整重复。

### 画面核对与反例

- 联系表显示教程本身主要由剪辑软件屏幕录制、参数操作和最终片段组成，适合学习流程拆分，不适合作为 Koubo 的视觉风格模板。
- 最终演示同时使用大量花字、贴图、卡片、进度条、人物抠像和多层时间线；公开评论中出现“成片看着累”的明确反例信号。
- 演示访谈中的嘉宾身份和内容为教程虚构，作者也在转录中说明嘉宾简介是编写的。该成片不能作为事实可信度或真实访谈质量证据。
- 具体美颜、颜色、字体和贴图参数高度依赖素材和软件，不进入 Agent 知识库。

## 3. D2：先识别表达功能，再选择可替换的剪辑动作

### 可迁移判断

1. **文案阶段可以提前留下剪辑意图。**
   - 时间码：`00:22–00:41`。
   - 作者观察到原视频的字幕入场、音效和缩放与文案节点相互对应，而不是后期随机补效果。
   - Director 含义：稿件确认后可标记“钩子、证据、转折、步骤、结果”等语义节点，但不得反向改写已批准事实。

2. **每段包装必须回答它服务什么表达功能。**
   - 时间码：`00:49–01:18`。
   - 作者把一段包装解释为账号背景与内容索引，而不只描述用了哪些动画。
   - Director 含义：先命名当前段落的功能，再让专家提出字幕、画面和声音候选。

3. **背书优先展示真实证据。**
   - 时间码：`01:22–01:40`、`02:17–03:05`。
   - 原视频用历史封面、公开反馈和创作者真实经历支撑可信度；作者认为这类证据画面可以保持简单。
   - Koubo 迁移：当内容声称做过、测试过或得到反馈时，优先使用真实截图、版本和结果，不用炫技替代证据。

4. **语义功能稳定，表现形式可以变化。**
   - 时间码：`01:58–02:15`、`03:32–03:47`。
   - 作者反复强调先抓住“这段为什么存在”，花字、画面和音效只是可替换实现。
   - Director 含义：不得把某位博主的具体包装做成固定配方；同一语义功能应允许多个引擎和视觉实现。

### 画面核对与反例

- 联系表显示本条采用画中画讲解、顶部章节条、巨大花字、评论截图、抠像和多层字幕，本身信息密度很高。
- 该视觉系统与美妆垂类、原博主人设和“拉片跟练”形式强相关，不能直接迁移到用户账号。
- “网感”“高级”等词没有稳定工程定义；只有被拆成可观察目的、时序和限制后才能进入技巧卡。

## 4. D3：AI 先提出有限选择，人负责选择和固化

### 可迁移判断

1. **不要把 Agent 工作伪装成一条指令完成。**
   - 时间码：`00:12–00:31`。
   - 作者说明成片经历五轮调整，并把交互过程而不是单一提示词视为核心。
   - Director 含义：记录版本、问题和返修理由；不得用“自动完成”隐藏人工选择。

2. **不知道工具能力时，先让系统陈述能力和边界。**
   - 时间码：`01:15–01:38`。
   - 第一版只有字幕动效，画面仍单调，证明“能运行”不等于达到表达目标。
   - Director 含义：引擎选择前先生成能力矩阵和最小样片，不因工具名称直接路由。

3. **难以语言描述审美时，生成有限选择题。**
   - 时间码：`01:42–02:21`。
   - 作者先用参考图说明需求，再让系统产生六个候选，由人选择字幕底色和章节样式。
   - Koubo 迁移：只展示差异明显的少量候选，保留“整体不接受”；参考图只用于抽象目的，不复制原风格。

4. **稳定后再资产化，不在第一版就固化。**
   - 时间码：`02:23–02:44`。
   - 作者在多轮调试后才把选择总结为 `design.md`，并计划在使用更稳定后再制作 Skill。
   - Director 含义：一次选中最多形成 Candidate；真实重复使用和用户批准后才允许晋升。

5. **明确适用边界。**
   - 时间码：`02:44–03:00`。
   - 作者承认自动剪辑并非万能，只声称当前适合其口播场景。
   - Koubo 迁移：任何自动化配方必须列出素材、画幅、表达难度和人工审核条件。

### 画面核对与反例

- 联系表显示本条采用浅色幻灯片、真人小窗、流程卡和底部字幕，适合展示流程，但不能证明其上一条视频真的达到“95% 自动完成”。
- 视频没有展示完整运行日志、所有五轮中间结果、人工耗时或失败次数，因此自动化比例属于作者自述。
- `design.md` 是作者的资产化方法，不是 HyperFrames 或 Remotion 自动保证的能力。

## 5. Director 候选知识

以下为 Codex 的跨视频抽象，不是三位作者的原始命名。全部保持候选状态。

### director-principle.freeze-structure-before-packaging.v1

- **问题**：方向或粗剪尚未稳定时，专家过早投入字幕、动效和声音，导致返工。
- **规则**：在昂贵包装前冻结一次语义连续的粗剪和内容时间线；出现素材缺陷或内容争议时先解决，不让包装掩盖问题。
- **证据**：D1 `01:00–01:28`、`04:01–06:39`。
- **反例**：确定性技术修复可以提前进行，但不得借此声称内容方向已确认。
- **验证方式**：场景决策测试；给出方向未确认、粗剪未确认和粗剪已确认三种输入，Director 只能在第三种输出全片包装提案。

### director-principle.semantic-role-before-effect.v1

- **问题**：剪辑动作由模板或“网感”驱动，无法说明为什么出现。
- **规则**：先为每个时间段标记表达功能，例如钩子、证据、转折、步骤、结果或章节导航，再让 Caption、Motion 和 Sound 针对该功能提出候选；实现形式可变，语义目的不可丢失。
- **证据**：D1 `06:42–08:21`、`26:59–27:24`；D2 `00:22–01:18`、`01:58–02:15`、`03:32–03:47`。
- **反例**：必要的连续性修复、降噪和裁切可以没有额外叙事功能，但必须记录为技术修复而非创意包装。
- **验证方式**：场景决策测试和一段真实口播的逐段语义映射。

### director-principle.offer-choices-then-freeze-after-evidence.v1

- **问题**：用户说不清审美时，Agent 自行猜测并立即固化为模板。
- **规则**：先生成少量差异明确的候选供人选择或全组拒绝；保存版本和返修原因；只有多轮稳定、完成复刻并经过用户批准后，才写入设计资产或 Skill。
- **证据**：D3 `00:12–00:31`、`01:15–02:44`。
- **反例**：编码、画幅、字幕安全区等确定性约束不需要每次生成审美选择题。
- **验证方式**：场景决策测试；验证 Director 不输出批准、发布或记忆晋升字段，并在用户全组拒绝时返回重构而非强制选优。

## 6. 当前结论

- D1 最适合训练生产阶段依赖和粗剪确认门；不适合学习其最终视觉密度。
- D2 最适合训练“语义功能先于效果”和真实证据优先；不复制其美妆垂类风格。
- D3 最适合训练多轮交互、有限候选和稳定后资产化；其自动化比例未经独立证明。
- 三条候选原则已完成各 3 个场景的声明式验证，但尚未取得第二级候选审核的真实片段试用准入，也未写入 Director 运行知识或正式知识状态。
