# AI口播剪辑 v3 实现与验证

## 当前架构

```text
打开AI口播工作台.vbs
  → node video/server.mjs（仅 127.0.0.1:8787）
  → AI生成新口播：本地证据汇总 + OpenAI兼容文本模型
  → 上传原片：只写入 video-jobs/
  → ffprobe + silencedetect
  → faster-whisper 本地中文逐字转录
  → 文本模型根据逐字稿生成 keepSegments 和 overlayCards
  → 根据口播视觉节点自动生成本地候选，并登记内容包/参考视频候选
  → 用户在素材审核板逐条批准、拒绝、替换或调整时间
  → 全部素材完成决策且合规检查通过后才允许渲染
  → FFmpeg 切段、30ms淡化、B-roll/画中画/前后对比、来源署名、逐字字幕、重点卡片、声音处理、画幅适配
  → 本地提炼封面文案并独立排版 9:16、3:4、16:9、4:3
  → final-v1.mp4 + 四张封面 + QA
  → 用户自然语言反馈
  → edit-plan-v2/v3… + final-v2/v3…
  → 用户最终审核通过
```

文本模型直接读取项目 `.env` 中的 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 和 `OPENAI_MODEL`。原视频不会传给模型；模型只读取脱敏文字、逐字转录和技术参数。

## 继承能力

- HyperFrames / 动态包装原则：只在钩子、证据、结果、经验节点放必要卡片；
- Video Use 原则：优先删除假启动、重复和明显错句，保留自然情绪；
- Promotion：成片支持 9:16、1:1 和原比例；封面支持 9:16、3:4、16:9 和 4:3；
- Video Cut：把模型决策约束为可执行、按源视频时间排序的 keepSegments；
- AI Video Workflow：上传、转录、计划、渲染、QA、审核、返修和版本记录闭环；
- Generative Media：自动拆解3—6个视觉节点，默认生成真人原片衍生动态画面、前后对比、工作流、项目证据和必要的AI视觉；纯文字卡片占比不超过20%，并继续由素材审核板逐条确认。

## v3 素材审核与版权门禁

- 初次剪辑不再直接渲染，计划完成后进入 `awaiting_asset_review`；
- 自动候选的视觉优先级为：真人口播 → 真实工作台/项目画面 → 同片前后对比 → 动态流程图 → AI生成视觉 → 少量动态文字；参考视频只在确有说明价值时截取2—5秒；
- 当前已实现从真人原片确定性生成动态对比、流程、提示输入和审核扫描画面，并登记本地项目证据与参考视频候选；生成失败才回退到静态信息卡；
- 外部素材必须保存创作者、作品、原链接、片段时长、使用目的、授权/引用依据和画面署名；
- 严格模式下，未明确授权的评论性引用被产品策略限制为单段10秒以内，并要求稿件自然说出创作者名称；标注来源不会被当作授权；当前创作实验可切换为 `rightsReviewMode=advisory`，此时版权依据和口播披露不阻塞，但来源、创作者、片段时间、画面署名和逐条审核仍保留；
- 每个候选必须变为“批准”或“拒绝”，有待决定项、缺文件、缺授权依据、缺稿件披露或未确认付费时，服务端拒绝渲染；
- 批准的图片或视频可按全屏B-roll、右上画中画、前后对比左侧/右侧合成；外部素材自动生成来源署名轨；
- `media-manifest-vN.json` 只有在 FFmpeg 成功解码成片后才把实际使用的素材写为 `composited: true`；
- QA 检查素材审核完成、批准素材有效且实际合成、外部元数据、来源署名和稿件披露；任一失败都阻止最终审核；
- 服务端继续支持严格费用门禁；当前网页创作模式把图像生成视为用户已预授权（`paidImageGenerationConfirmation=false`），不逐次因生图费用中断。素材审核、版本保留和禁止自动发布不受该开关影响。

## 2026-07-22 完整预览与分段小样审核

- 孤立素材卡不再是主要审核入口：用户可以点击“自动采用本地素材并生成完整预览”，系统自动批准具备本地文件和有效时间段的免费/本地素材，并拒绝外部、付费、缺文件或缺时间段候选；
- 素材决定完成后仍先运行真实合成与QA，再生成 `review-preview-vN.mp4`（720×1280审核预览）和 `review-bundle-vN.json`；
- 每个已采用视觉节点会保留前后口播上下文，重叠节点自动合并，形成15—30秒的 `review-segment-vN-NN.mp4` 小样和缩略图；
- 网页默认播放完整审核预览，并在下方列出所有小样。用户可按“完整片时间点”或“小样编号＋小样内时间点”反馈；
- 高清母版、完整manifest和QA仍按版本保留，但在用户点击最终审核通过前不会发布，也不会覆盖原片。

## 2026-07-21 v3 端到端验证

使用8秒本地合成竖屏视频完成验证：任务在剪辑计划后停于素材审核板；8个候选全部完成批准/拒绝后才可启动渲染。第一版批准本地生成信息卡，manifest记录1个素材真实合成；第二轮附加一个测试授权视频，服务端先成功拦截“稿件未说明创作者”，补齐测试披露后以画中画方式完成合成并生成来源署名。最终输出1080×1920、H.264/AAC/yuv420p、BT.709，素材QA全部通过，`final-review.json` 记录两个实际合成素材且 `autoPublish: false`。

## 2026-07-16 v2 端到端验证

测试输入：本地 Windows 中文 TTS 生成的 14.2 秒竖屏口播，包含明显长停顿。原片为 720×1280、H.264/AAC。

验证结果：

- 本地 `faster-whisper/tiny` 成功生成真实语音时间轴；生产默认模型为 `small`；
- 检测到 3 段静音；
- 文本模型生成保守剪辑区间、字幕和钩子/证据/结果卡片；
- v1 输出约 8.6 秒，1080×1920、30fps、H.264、AAC、yuv420p；
- 完整解码、编码规格和时长匹配 QA 全部通过；
- 自然语言反馈“保留第一句后的自然停顿，重点卡片只保留两张，字幕保持逐字时间轴”成功生成 v3；
- 返修结果保留指定自然停顿、卡片强制限制为 2 张、逐字字幕继续使用真实时间轴；
- 版本 1—3 和两条返修记录均保留；
- 最终 `approve` 生成 `final-review.json`，状态为 approved；
- 请求不存在的 `favicon.ico` 返回 404 后，服务仍保持在线。

## 降级策略

- Whisper 模型暂时无法下载或转录失败：退回当前口播稿 + 停顿检测，不阻塞生成基础成片，并在网页明确显示降级原因；
- 文本模型剪辑决策失败：退回本地停顿剪辑；
- 返修模型失败：保留上一版可审核成片，不覆盖已有结果；
- 任一步失败：任务进入 error，可在网页点击重试；原片不被覆盖。

## 日常验收

真实拍摄仍应重点检查：

- 中文专有名词和断句；
- 真人脸部安全区；
- 错句删除是否改变原意；
- 重点卡片是否遮挡人物；
- 手机端节奏和平台上传兼容性。
