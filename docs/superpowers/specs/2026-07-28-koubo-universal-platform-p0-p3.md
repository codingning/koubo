# Koubo 通用口播平台 P0–P3 实施规格

状态：Ready（用户于 2026-07-28 确认）

## 目标

把当前面向单一个人 AI 成长账号的 Koubo，升级为任何本地用户都能使用的通用口播平台：用户可以选择任意内容方向、受众、目标、语气和时长，生成口播稿，上传真人原片，经过现有 Visual Director v4、素材审核、关键帧审核、动态样片审核、完整渲染、QA 和人工最终审核完成剪辑。

本地版是本轮可交付产品；公网多用户版只建立可迁移的用户、权限、存储和插件边界，不在本轮部署或开放公网。

## 硬约束

- `visual-director-v4`、`keepSegments`、版本化审核和 `trial → approved → promoted` 继续是唯一生产总控。
- 第三方 Skill 不得建立第二套任务状态、剪辑决策或审核系统。
- 新能力必须通过窄适配器、派生 artifact 或镜头资产注册表接入。
- 原媒体默认只在本机处理；任何云上传、付费生成和发布继续需要当次确认。
- 不覆盖旧任务、旧成片、旧剪映草稿或旧审核记录。
- 合并、推送、部署和公开发布必须等待用户最终批准。

## 分阶段范围

### P0

1. 固定 Node、Python、HyperFrames、FFmpeg 和可选导出依赖。
2. 本地 API 仅允许可信同源入口；写操作要求启动时随机会话令牌。
3. 自动检查 Skill、README、运行时和锁定版本漂移。
4. 建立只读 `Exporter` 合同；导出器不能修改 `job.json`、时间线或批准状态。

### P1

1. 从批准的 `timeline-vN.json` 生成不覆盖旧草稿的剪映工程，并独立验证片段、时长、源范围和 30ms 淡化。
2. 为参考视频生成带来源、时间戳、Hook、镜头、节奏、音频、可借鉴、禁止复制和不确定项的 `reference-distillation-v1.json`。
3. 提供 PageCam 本地页面截图、元素切片和 `layout.json` 捕获工具，产物进入镜头资产注册表后才能使用。
4. 素材支持 `exact / semantic / hybrid` 锚点；旧的绝对时间 placement 保持兼容。

### 通用产品层

1. UI 不再默认绑定个人、AI 成长账号、30 天路线或固定内容方向。
2. 新增工作区、内容领域、目标受众、视频目标、语气、语言和目标时长。
3. 本地记录带稳定 `workspaceId`；列表和新任务按工作区过滤。公网版未来用认证主体替换本地工作区头，不改变领域模型。
4. 默认提供通用示例，原个人内容只作为迁移后的历史示例保留。

### P2

1. 权威 JSON 派生 `STORYBOARD.md/json`，禁止从 Markdown 反写状态。
2. 建立 5–10 个高频真实 UI/证据镜头的注册表。
3. 建立许可清晰的本地 SFX cue 和 speech-aware ducking 合同；默认不加 BGM。
4. 每期生成 `video-retro-vN.json/md`；不得自动晋升长期规则。
5. Director 按镜头选择 HyperFrames、FFmpeg 或可选 Remotion，并记录理由和 fallback。

### P3

Collage、WhisperX、Manim 只注册为默认关闭的插件能力。启用时必须显示依赖、隐私、费用和适用条件；没有具体需求时不得安装、下载模型或调用云服务。

## 完成标准

- 原始 Node、Python、工作台测试继续通过。
- 新模块具有合同和路由测试，安全测试覆盖不可信 Origin、缺少令牌和只读请求。
- 通用 UI 在真实浏览器中可创建非 AI 方向口播，且个人成长文案不再是默认入口。
- 剪映导出使用真实本地媒体生成新草稿目录，JSON 验证通过；若本机安装剪映，则还需真实打开检查。
- PageCam 使用真实本地页面生成整页截图、至少一个元素切片和 `layout.json`。
- 所有 P3 插件默认关闭，健康接口明确报告原因。
- 最终生成合并前报告并停在用户批准门，不自动合并或推送。
