# 创作者内容证据库：14 天付费验证包 v1

状态：`validation_only`
验证周期：2026-08-17 至 2026-08-31
最高优先决策：`DEC-KOUBO-CREATOR-EVIDENCE-LIBRARY-001`

## 要验证的产品假设

为持续输出的中文知识型创作者，把散落在短视频平台、网页和本地文件中的收藏，整理为私有、可追溯、能直接支持选题和成稿的内容证据库。

首版不是 SaaS，而是一次边界固定的付费建库冲刺：

1. 接收 50—100 条真实收藏、链接或导出记录；
2. 建立带原链接、作者、时间点、摘要和来源边界的本地证据库；
3. 区分来源观点、用户判断与 AI 推断；
4. 交付 3 个账号匹配的选题证据包；
5. 观察用户是否在 7 天内真正采用一个选题或再次主动查询。

## 首批用户边界

必须同时满足：

- 中文知识型创作者、讲师、顾问或小型内容团队；
- 每月至少发布 4 条内容；
- 已积累 100 条以上收藏或素材；
- 最近 30 天出现过找不到原素材、出处或原观点造成的返工；
- 愿意以导出文件、链接清单或明确授权的本地操作提供真实数据。

不招募：只想体验 AI 总结、没有持续发布任务、拒绝提供任何真实素材、要求代运营或承诺流量的人。

## 通过门槛

- 10 人中至少 5 人提供真实收藏或导出数据；
- 至少 3 人在交付前支付定金；
- 至少 2 人在 7 天内实际采用一个选题或第二次主动查询；
- 单人标准交付时间不超过 3 小时；
- 返修能够被一次有界纠错控制，不演变为开放式定制。

未同时通过以上门槛，不把该方向写成已验证主产品，也不继续扩建功能。

## 14 天执行顺序

0. 先按 [INTERNAL_V0.md](INTERNAL_V0.md) 用用户自己的 50—100 条真实收藏做出可打开、可演示、可交付的内部 V0；用户结果验收前不招募。
1. 用 [SCREENER.md](SCREENER.md) 筛出 10 名合格候选。
2. 按 [INTERVIEW_GUIDE.md](INTERVIEW_GUIDE.md) 完成问题访谈，不先演示功能。
3. 对确认存在真实返工的人给出 [OFFER.md](OFFER.md) 中的正式报价和定金要求。
4. 按 [DELIVERY_CONTRACT.md](DELIVERY_CONTRACT.md) 交付，不临时扩张范围。
5. 用 [PILOT_LEDGER.csv](PILOT_LEDGER.csv) 记录授权、付款、交付工时和 7 天复用。
6. 内容只按 [CONTENT_RECRUITMENT_PLAN.md](CONTENT_RECRUITMENT_PLAN.md) 服务同一用户和同一产品承诺。

## 暂停开发规则

验证期内不因为单个访谈意见新增平台、移动端、自动写稿、团队协作、云同步或新模型能力。只有三个以上已付款用户重复遇到同一阻断，才将其登记为下一版候选。

## 权限边界

本目录只是验证材料，不代表已经对外发布。当前阶段只允许使用用户自己的本地数据构建内部 V0。未经用户新的明确授权，不发布招募信息、不私信候选人、不创建收费页面、不收款，也不读取任何第三方私有收藏数据。
