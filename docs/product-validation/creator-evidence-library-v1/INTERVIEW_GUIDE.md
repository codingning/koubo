# 问题访谈指南 v1

目标：确认问题是否真实、频繁且有代价，不向用户推销预设方案。建议 25—35 分钟。

## 开场

“这次不是产品演示。我想先还原你最近一次从收藏或资料中寻找内容的真实过程。没有标准答案，我也可能最后判断这个产品不值得做。”

征得是否允许记录结构化笔记；未经明确授权，不录音、不保存私密原文。

## 核心问题

### 1. 最近一次事件

- 最近一次需要从过去收藏里找资料，是为了完成什么内容？
- 当时先做了什么？然后发生了什么？
- 最后找到了吗？用了多久？
- 如果没找到，你怎么替代或放弃的？

### 2. 真实损失

- 这次事件造成了什么后果：延期、放弃、重复研究、错误引用，还是没有影响？
- 过去一个月发生过几次？
- 如果什么都不改变，未来三个月会有什么实际影响？

### 3. 现有替代方案

- 现在用收藏夹、Notion、Obsidian、表格还是搜索解决？
- 哪一步最费时间？
- 过去是否为类似工具、课程或人工服务付过费？购买后真正使用了多久？

### 4. 输出任务

- 你真正需要的是找到原资料、获得选题、核对证据，还是完成脚本？只能选一个最重要的。
- 如果给你 3 个选题证据包，你会在什么时间、哪条内容中使用？
- 你如何判断一个证据包“可以直接用”？

### 5. 信任与数据

- 哪些资料绝不能离开本机？
- 你是否愿意提供链接清单或导出文件？为什么？
- 本地隐私和零配置移动端使用发生冲突时，你优先哪一个？

## 访谈后证据评级

- `E0`：泛泛表达兴趣，没有最近事件。
- `E1`：有最近事件，但没有明显损失或频率。
- `E2`：有重复问题、明确返工和现有替代方案。
- `E3`：愿意提供真实数据并安排下一步。
- `E4`：在看过固定范围后支付定金。
- `E5`：7 天内实际采用结果或主动再次查询。

只有达到 `E3` 才给报价；只有 `E4/E5` 才计入产品验证。

## 禁止诱导

- 不问“你是不是很需要这个产品”。
- 不把“愿意看看”记录为购买意愿。
- 不先展示完整功能再询问痛点。
- 不用播放量、竞品用户数或其他人报名制造从众压力。
