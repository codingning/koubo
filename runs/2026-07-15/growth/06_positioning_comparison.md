# 旧热点版与新AI成长版定位差异｜2026-07-15

## 结论

旧版不是技术失败，而是账号主线与当前目标不匹配。旧版继续作为热点辅助模块和基线样本；新版把“当天真实AI实践”提升为内容入口。

| 维度 | 旧热点版 v1 | 新AI成长版 v2 |
|---|---|---|
| 账号承诺 | 每天筛选综合热点并给普通人角度 | 普通人从零学AI，用AI做真实项目，公开进度、结果和踩坑 |
| 内容起点 | 抖音、小红书、微博、AI和国际热榜 | 当天Codex任务、文件、作品、错误、截图和昨日挑战 |
| 热点角色 | 主选题池核心 | 相关问题、传播切口、亲测对象和标题辅助 |
| 故事单位 | 每天一个相对独立的热点 | 30天连续成长故事中的一集 |
| 证据 | 官方公告、媒体、热榜和评论 | 本人文件、功能、运行结果、错误、前后对比；外部事实仅辅助 |
| 候选数量 | 默认必须5个 | 最多5个；没有真实素材可以留空 |
| 评分重点 | 时效、相关、新奇、可讲、互动、可信 | 真实性、主线连续、观众价值、变化结果、画面、明日挑战和可行性 |
| 主选硬门槛 | 可信、可讲、低风险 | 真实实验、直接证据、可展示结果、观众经验、连续性和明日挑战 |
| 口播开头 | 热点冲突、结果或反常识 | 本人真实结果、失败、返工或挑战 |
| 口播结尾 | 观众讨论问题 | 明天继续验证什么，或选择下一个真实实验 |
| 台账 | 选题、标题、封面和传播数据 | 额外记录成长天数、项目路线、证据、错误、经验、明日挑战和学习结论 |
| 周复盘 | 只复盘内容表现 | 分开复盘个人学习和账号内容，再做交叉判断 |
| 自动化 | 3天热点试运行后再定时 | 先证明真实任务能稳定转成好内容；仍不自动发布和评论 |

## 旧版保留价值

1. 热点来源矩阵、事实核验和平台降级能力继续使用；
2. 旧Day 1可以作为“观众记住新闻还是记住创作者”的比较基线；
3. 旧评分和素材包保留在文件与Excel旧表中，便于未来复盘；
4. 新版没有重复建设热点采集，而是把它降为支持模块。

## 新样例验证结果

- 主选题来自今天真实的工作流方向修正；
- 有旧版、新版、Excel、错误和校验等直接证据；
- AI热点亲测和粉丝共创两类因无真实素材而留空；
- 完整稿约362个口播字符，按250字/分钟约87秒；
- 精简稿约177个口播字符，约43秒；
- 结构校验通过；
- Excel旧数据保留，新增成长型工作表，公式错误扫描0项；
- 自动发布和自动评论仍关闭。
