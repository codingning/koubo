# 本地AI剪辑服务

本目录提供 `打开AI口播工作台.vbs` 背后的本地服务。

- 只监听 `127.0.0.1:8787`；
- 原视频和成片只写入项目内 `video-jobs/`；
- 不自动上传视频；
- 使用 FFmpeg 完成停顿检测、无损逻辑切段、音频淡化、响度标准化、竖屏/方形适配、字幕烧录和 H.264/AAC 导出；
- 网页生成 `edit-plan.json`，Codex 可通过项目 Skill 继续进行语义化剪辑、动态卡片和多版本包装；
- HyperFrames / video-use 属于可选增强能力，使用云端转写或生成服务前必须再次确认上传范围。

## 启动

普通用户无需运行命令，双击项目根目录：

`打开AI口播工作台.vbs`

开发调试：

```powershell
node .\video\server.mjs
```
