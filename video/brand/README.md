# 三金AI实战个人 IP 动效

sanjin-ip-sting-v2.html 是用户已通过主观审核的 3 秒默认品牌片头；v1 仅保留用于回滚和对比。

- 默认位置：每期第一段完整结束后；以第一段结束点为时间锚，不写死第 3 秒，并将后续轨道整体顺延。
- 默认时长：3 秒，可在 2.8—3.2 秒内微调。
- 固定识别：知识→实测→结果三段轨道、三道电蓝横线、结果金色菱形、“三金AI实战”和“从知道到做到”。
- 声音标记：audio/sanjin-ip-sonic-v2.wav，使用三音上行、冲击与电子落点同步品牌锁定。
- 字幕关系：组件位于内容画面之上、字幕之下；口播字幕不可被品牌动效遮挡。
- 复用方法：复制到视频项目的 compositions/overlays/，使用同名 data-composition-id，在主时间线以独立 sub-composition 挂载。
- 边界：品牌动效不能挤占前三秒钩子，不能把第三方素材作者错误标成三金，也不能自行改变账号名称或品牌内核。
