# AI口播工作台网页

## 打开方式

无需运行PowerShell或其他脚本，直接双击项目根目录中的：

- `打开口播工作台.html`；或
- `打开口播工作台.url`。

也可以直接打开：`web/index.html`。

## 最简单的使用方法

1. 双击 `F:\code\koubo\打开口播工作台.html`；
2. 首页先确认“当前拍摄包”，页面会直接显示推荐精简稿；
3. 点击“照着念”使用完整版、精简版或全屏提词器；
4. 点击“拍什么画面”查看B-roll和字幕提示；
5. 最后选择标题、封面并填写审核意见。

当前可拍内容的完整素材包位于：

`F:\code\koubo\runs\2026-07-15\growth\02_main_package.md`

网页首页也会直接显示并提供这个文件的入口，不需要再到目录里寻找。
## 网页能做什么

- 首页直接告诉你当前要拍什么；
- 查看完整版、精简版和分段情绪提示；
- 提词器自动滚动，可调字号和速度；
- 复制口播稿和三平台发布文案；
- 选择标题和封面方案；
- 填写审核状态与修改意见；
- 勾选B-roll、拍摄准备和风险检查；
- 查看30天成长路线和旧定位基线；
- 将审核结果复制给Codex或导出JSON。

所有审核选择和个人修改默认保存在浏览器的 `localStorage` 中，不会覆盖Markdown、Excel或原始资料，也不会连接抖音、小红书、微博账号。

## 内容更新方式

以后Codex生成新的每日口播后，应同步更新：

- `web/data/content-data.js`

用户只需要重新打开或刷新网页，不需要运行采集和生成脚本。

## 安全边界

- 网页完全本地运行；
- 不自动发布、不自动评论；
- 不上传文件；
- 不向网络发送审核记录；
- 导出的审核JSON由用户自行决定是否发送给Codex。
