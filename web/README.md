# AI口播工作台网页

## 推荐入口

双击项目根目录的 `打开AI口播工作台.vbs`

## 内容定位

网页面向 Codex、Agent、Skill 开发者与进阶用户，单独展示目标场景、立即可执行动作、真实证据、资源交付、评论分叉和下一次验证。

旧“30天成长/从知道到做到”内容只保留在历史库，不再驱动新选题。新内容不设Day编号和日更目标，只有真实运行结果与提示词、工作流图、清单或模板准备完成后才进入写稿。

## 使用流程

1. 首页点击“AI生成新口播”；
2. 查看稿件、提词器、B-roll、标题和封面；
3. 拍完后进入“拍完AI剪辑”，选择原视频；
4. 点击一次“上传并开始全自动剪辑”；
5. 等待本地转录、AI剪辑、字幕、包装、渲染和 QA；
6. 最后观看成片：没有问题就“审核通过”，有问题就直接写自然语言意见并生成新版本。
7. 审核通过后进入“发布准备”：选择标题，编辑抖音、小红书和视频号文案，下载 9:16/16:9 封面或完整 ZIP 素材包。

AI 生成内容由 `/api/contents` 动态合并到原有静态内容库，不再要求手动更新 `web/data/content-data.js`。静态数据仍作为无服务时的回退内容。

## 安全边界

- 原视频只上传到本机 `127.0.0.1` 服务；
- 网页不连接抖音、小红书、微博账号；
- 不自动发布、不自动评论；
- 审核和返修记录只保存在本地任务目录。
